# 分页条单行紧凑化（不透明、不再换行压占数据区）：改动前后对照取证

- 反馈：「下一页等切换按钮需要在更合适的位置，当前显示还是挡住了数据」。
  Before（`e344d11`，PR #56 首版之后）：分页条在 500px 窄面板下换行成 **2 行**（实测 468×80px），
  半透明底色（rgba(120,120,128,.08)），多行条带压在数据区下缘；
  After（本分支）：分页条单行 **468×36px**、底色不透明（宿主画布 token，亮色实测 rgb(255,255,255)）、
  控件 24px 高短内距，窄面板横向滚动兜底——不再以多行半透明条带压占数据区。
- 场景：数据预览第 1 页默认态与筛选生效态（两版筛选行为一致，本变更只改分页条布局与底色）；
  viewport 500×774，@2x 采集，亮/暗各一组；colorScheme 显式同侧，画布底色取宿主主题 token 解析值。
- DOM 量化（probe-footer.txt，Playwright boundingBox + computedStyle 实测）：
  `[before] footer=468x80 lines~2 footerBg=rgba(120,120,128,.08)`；
  `[after] footer=468x36 lines~1 footerBg=rgb(255,255,255)`
- 像素机器校验（pixel-checks.json）：8 图与底色亮度差 > 60 的文字像素占比全部 > 0。
