# 数据预览分区结构对齐 Navicat 数据编辑器：改动前后对照取证

- 拆解依据：Navicat 18 官方手册数据编辑器章节（前序 REA 会话从随包 PDF 提取）的分区构成——
  **网格上方工具条**（「Filter & Sort」按钮在此）→ **满幅紧凑网格** → **底部记录导航条**
  （Record Bar：图标翻页 + 页码框 + 记录总数右对齐）。
- 结构对齐项（本分支）：
  1. 筛选入口从底部记录条移到**网格上方工具条**（`▽ 筛选 · N`，生效时高亮 primary）；
  2. 底部记录条改为 Navicat Record Bar 同构：图标按钮 `|◀ ◀ [第 n / m 页] ▶ ▶|` + 记录总数右对齐
     （按钮带 title/aria-label，读屏与悬浮提示保留）；
  3. 浏览网格取消圆角卡片观感（`.dbt-browse-root .dbt-browse-tablewrap` 直角满幅，对齐 Navicat 网格样式）。
- 场景：数据浏览 → main 库 → orders 表（123 行）→ 数据预览；场景 1 = 第 1 页默认态
  （工具条 + 图标记录条 + 直角网格）；场景 2 = 窗格展开 3 条件行；场景 3 = 筛选生效态
  （两版均真实请求并出「匹配 N 行」，功能等价）。
- Before = `e344d11`（PR #56 首版后：筛选按钮在底部记录条、文字按钮分页、圆角卡片网格）；
  After = 本分支工作区。
- viewport 500×774，@2x 采集，亮/暗各一组；colorScheme 显式同侧，画布底色取宿主主题 token 解析值。
- 两版均为各自提交真实构建 `dist/` + 各自真实 `client.js` + 真实插件 HTTP API，React 真实渲染，
  数据源为真实 sqlite 示例库（orders 123 行）。
- 像素机器校验（pixel-checks.json）：12 图文字像素占比全部 > 0。
- 功能回归：客户端 316 例全绿（图标按钮按 aria-label 寻址）；全量套件除 4 例本机 hotfix 环境差异
  （master 基线同样失败）外全部通过。
